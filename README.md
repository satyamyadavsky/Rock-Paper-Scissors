# ✊ Rock Paper Scissors Game

A simple and interactive Rock Paper Scissors game built using **HTML, CSS, and JavaScript**. Play against the computer and see who wins!

## 🚀 Features

- User-friendly interface
- Play against the computer
- Random computer choices
- Instant result display
- Score tracking
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎮 How to Play

1. Open the game in your browser.
2. Choose Rock, Paper, or Scissors.
3. The computer will randomly select its choice.
4. The winner will be displayed automatically.
5. Enjoy playing and improve your score!

## 📂 Project Structure

```text
Rock-Paper-Scissors/
│
├── index.html
├── style.css
└── script.js
```

## 💻 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run `index.html` in your browser.
4. Start playing!
